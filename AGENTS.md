# Arc Workflow — Agent Configuration

This file configures how the Arc engineering skills operate in this repo. The
`## Agent skills` block below is generated by the `setup-arc` skill; edit the
linked `docs/agents/*.md` files to change behaviour.

## Agent skills

### Issue tracker

Issues tracked in GitHub Issues on `mikeartee/arc-workflow` via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Canonical label vocabulary (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `tracking`, `wontfix`). See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `CONTEXT.md` + `docs/adr/` at the repo root. See `docs/agents/domain.md`.

### Ship style

Pull request: feature branch + PR with `Closes #<issue>`, human merges. See `docs/agents/ship-style.md`.

### Project board

GitHub Projects v2 board "arc-workflow" (<https://github.com/users/mikeartee/projects/11>). See `docs/agents/project-board.md`.
